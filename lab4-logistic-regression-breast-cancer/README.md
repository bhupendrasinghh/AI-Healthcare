# Lab 4 — Logistic Regression on Breast Cancer Wisconsin (Diagnostic) Dataset

**Course:** CSET343 - AI in Healthcare  
**Topic:** Binary Classification · Logistic Regression  
**Author:** Bhupendra Singh

## 📋 Overview

This lab applies **Logistic Regression** to the **Breast Cancer Wisconsin (Diagnostic)** dataset to classify tumours as **Malignant** or **Benign**. It covers the full ML pipeline — data loading, preprocessing, model training, evaluation, and visualisation.
